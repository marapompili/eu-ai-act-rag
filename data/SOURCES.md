# Data sources

- **Document:** Regulation (EU) 2024/1689 (Artificial Intelligence Act), original Official Journal text of 12.7.2024.
- **Source:** EUR-Lex, https://eur-lex.europa.eu/eli/reg/2024/1689/oj (ELI: http://data.europa.eu/eli/reg/2024/1689/oj), English version.
- **Downloaded:** 2026-10-22, saved manually from the browser as HTML to `data/raw/ai_act_oj.html`
  (EUR-Lex blocks automated downloads with a bot challenge).
- **Not included:** later amendments. EUR-Lex lists a consolidated version, which this project does not use.
- **Reuse:** the text is not redistributed in this repository; each user downloads it from EUR-Lex.
  Credit: European Union, EUR-Lex.
